# 🧩 Sudoku Solver in Go

Цей репозиторій містить реалізацію класичного Sudoku-розв'язувача, написаного на мові Go (Golang). Програма використовує метод **backtracking** для знаходження розв’язку заданої Sudoku-головоломки.

## 📦 Вміст репозиторію

```
.
├── main.go         # Основна програма з розв'язувачем Sudoku
└── README.md       # Цей файл з описом
```

## 🚀 Швидкий старт

### Вимоги
- Go 1.20+

### Запуск

1. Клонувати репозиторій:

```bash
git clone https://github.com/hanashiko/sudoku-solver-go.git
cd sudoku-solver-go
```

2. Запустити:

```bash
go run main.go
```

Програма виведе розв’язок (якщо він існує) для зашитої в код Sudoku-головоломки.

## 🧠 Як це працює

### Основні функції:

- `print_grid(grid [9][9]int)`  
  Друкує Sudoku-сітку у читабельному вигляді.

- `find_empty_location(grid, &position)`  
  Знаходить першу порожню клітинку (тобто клітинку з 0).

- `used_in_row`, `used_in_column`, `used_in_box`  
  Перевіряють, чи число вже використано у відповідному рядку, стовпчику або 3×3 блоці.

- `is_safe`  
  Перевіряє, чи безпечно вставити число в конкретну клітинку.

- `solve(grid *[9][9]int)`  
  Основний рекурсивний алгоритм на базі **backtracking**, що розв’язує головоломку.

- `main()`  
  Точка входу. Можна вказати будь-яку стартову Sudoku-сітку.

## 📥 Вхідні дані

Sudoku-сітка задається у вигляді 9×9 масиву `grid`, де `0` означає порожню клітинку. У `main()` можна змінити `grid`, щоб протестувати інші головоломки.

```go
var grid [9][9]int = [9][9]int{
    {0, 0, 3, 0, 4, 5, 0, 0, 0},
    ...
}
```

## 📘 Примітки

- Підтримується лише класичний формат Sudoku (9×9).
- Алгоритм гарантує знайдення рішення, якщо воно існує.
- Якщо рішення не існує, виводиться відповідне повідомлення: `No solution exists`.
